# Sedrava ecosystem website update — 2026-11-23

This source update covers three public-facing surfaces without changing production application/server code:

1. Existing official Astro/Starlight website — new bilingual native Rust and SedravaSQL documentation pages, release/roadmap/getting-started updates, homepage links, and sidebar navigation.
2. SedravaSQL mini-site section within the official documentation host at /sedravasql/ and /ru/sedravasql/. A standalone SedravaSQL domain has **not** been registered or claimed.

## Source of truth and restrictions

No new registered standalone domain, no TLS public API, no runtime DB data or password/SSH keys added to the repository.
Physical power-loss guarantees, multiwriter public service, general SQL, runtime schema migration and SQL write DSL remain unverified or unimplemented.
