**Sedrava 0.12.0-alpha.3** is the current Rust toolchain. Experimental alpha, not production-ready. [Downloads](https://sedrava.virtreal.ru/downloads/0.12.0-alpha.3/) · [GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.12.0-alpha.3).

- Expand typing and Web/Android generators.
- Optimize SQL, HTTP and UI.
- A24–A28: migrations, project CLI, integration, Forgejo CI and offline package verified. A29–A30: documentation, verified package and public alpha releases completed.
- Generated client/API/database integration.
- Develop self-host A5.11b.
- Windows/macOS builds and actual browser/device tests.
- Beta/stable acceptance gates.

[Full roadmap](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/ROADMAP.md).
