## A small Sedrava program

~~~text title="hello.sdr"
app "Hello Sedrava"
state count = 0
action add: count = count + 1
rule count >= 0 and count <= 10
test once: add -> count == 1
screen main:
    text "Hello Sedrava"
    value count
    button "Add" -> add
~~~

Use <code>sedrava check</code> to validate, <code>sedrava test</code> to run embedded tests and <code>sedrava build web</code> or <code>sedrava build android</code> to generate a target.
