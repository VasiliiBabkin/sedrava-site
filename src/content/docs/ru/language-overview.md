Sedrava 0.9 — намеренно небольшой язык для локальных приложений. Исходные файлы имеют расширение **.sdr**. Синтаксис и идентификаторы записываются на английском.

## Состояния и вычисляемые значения

Поддерживаются два типа состояния: **знаковые 32-битные целые числа** и **логические значения**. Вычисляемое значение зависит от состояния, присваивать его напрямую нельзя.

~~~text
state goal = 5
state progress = 0
derive reached = progress >= goal
~~~

Чтобы хранить принятое состояние между запусками интерфейса, используется объявление **persist**.

## Атомарные действия и инварианты

Действия последовательно изменяют копию состояния. Переполнение или нарушение итогового правила отклоняет всё действие — частичные изменения не сохраняются.

~~~text
action add:
    if progress < goal:
        progress = progress + 1
rule goal >= 1 and goal <= 20
rule progress >= 0 and progress <= goal
~~~

Правила проверяются по окончательному состоянию. Вычисляемые значения должны оставаться вычислимыми после каждого присваивания.

## Тесты и интерфейс

Встроенный тест начинает работу с исходного состояния и независимо выполняет заданные действия.

~~~text
test once: add -> progress == 1
screen main:
    text "Progress"
    value progress
    value reached
    button "Add" -> add
~~~

Интерфейс 0.9 поддерживает текст, значения, кнопки, числовой ввод и условное отображение текста. Сейчас доступен **один экран** с вертикальной компоновкой.

## Команды

| Команда | Назначение |
| --- | --- |
| sedrava check FILE | Проверка синтаксиса, типов и правил |
| sedrava test FILE | Запуск встроенных тестов |
| sedrava run FILE ACTION... | Выполнение действий, вывод состояния в JSON |
| sedrava build web FILE --output PATH | Генерация автономной HTML-страницы |
| sedrava build android FILE --output DIR | Генерация Android/Compose-проекта |

## Что пока не поддерживается

Нет строкового состояния, коллекций, файлов, асинхронных операций, автоматических таймеров, модулей и переходов между экранами. Для сохранения Web использует localStorage, Android — SharedPreferences. Эти хранилища не предназначены для секретов, миграций пока нет.
