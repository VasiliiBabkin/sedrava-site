Sedrava развивается постепенно. Номера версий — ориентиры, **не сроки выпуска и не обещания**.

| Этап | Основное направление | Статус |
| --- | --- | --- |
| **0.9** | Состояния, действия, инварианты, тесты, базовые генераторы Web/Android | Опубликованная альфа-версия GitHub |
| **0.10** | Текстовый ввод, расширенный интерфейс, темы, навигация, несколько экранов | Проверенный кандидат 0.10.0rc2 объединён с main; публикация экспериментального GitHub-релиза ожидается |
| **0.11** | Дальнейшее развитие языка и хранения данных (объём не утверждён) | Планируется; записи и коллекции реализованы в 0.10 |
| **0.12–0.13** | Возможности устройства, модули, повторно используемые компоненты | Планируется |
| **0.14–0.15** | Инструменты редактора и настольные приложения | Планируется |
| **0.16–0.19** | Надёжность, безопасность, доступность и совместимость | Планируется |
| **1.0** | Спецификация и политика стабильности | Долгосрочная цель |

## Принципы разработки

- Описывать поведение приложения вместо платформенного шаблонного кода.
- Сохранять одинаковую семантику действий и правил на разных платформах.
- По возможности создавать приложения, работающие без сервера.
- Явно объявлять доступ к возможностям устройств и сохранение данных.
- Не путать протестированный код с опубликованным выпуском.

Визуальный конструктор и дополнительные платформы — более отдалённые идеи. Инструменты с ИИ могут появиться позднее, но сам язык должен работать без них.

Главный документ проекта — [дорожная карта в репозитории](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/ROADMAP.md). Реальные приоритеты разработки могут измениться.

Предложить изменение или сообщить об ошибке можно в [GitHub Issues](https://github.com/VasiliiBabkin/sedrava/issues).
