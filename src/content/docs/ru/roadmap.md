Sedrava [0.10.0](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0) опубликована 31 октября 2026 года и доступна на [PyPI](https://pypi.org/project/sedrava/0.10.0/). Номера будущих этапов — ориентиры, а не сроки и гарантии.

| Этап | Направление | Статус |
| --- | --- | --- |
| **0.9** | Базовые состояния, действия, арифметика, Web/Android | Историческая альфа GitHub |
| **0.10** | Unicode-текст, типизированные записи, ограниченные списки, навигация | **Опубликована** на GitHub и PyPI |
| **0.11** | Адаптивный Web UI и генерация сайтов | **Черновой PR №22**, отсутствует в 0.10.0 |
| **0.12+** | Возможности устройств, модули, редакторы и стабилизация | Предложения без сроков |
| **1.0** | Версионированная спецификация, гарантии совместимости | Долгосрочная цель |

## Текущая разработка

В [черновом PR 0.11](https://github.com/VasiliiBabkin/sedrava/pull/22) развивается генерация адаптивных статических сайтов из `.sdr`: компоненты, темы и проверка ресурсов. **Функция ещё не опубликована**. Этот официальный сайт документации создаётся отдельно через Astro/Starlight в [sedrava-site](https://github.com/VasiliiBabkin/sedrava-site).

## Принципы

- Описывать поведение и типизированные состояния вместо служебного платформенного кода.
- Сопоставлять семантику Python, Web и Android.
- Устанавливать явные ограничения, по возможности работать без сервера.
- Не выдавать разработки в ветках за опубликованные возможности.
- Честно описывать границы проверок, включая неподтверждённые устройства.

Главный документ — [дорожная карта языка](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/ROADMAP.md). [Известные ограничения](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/KNOWN_LIMITATIONS.md). Планы могут меняться.
