**Sedrava 0.12.0-alpha.2** — текущая линия, основная реализация на Rust. Экспериментальная alpha, не для production. [Загрузки](https://sedrava.virtreal.ru/downloads/0.12.0-alpha.2/) · [GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.12.0-alpha.2).

- Расширение типизации и генераторов Web/Android.
- Оптимизация SQL, HTTP и UI.
- Интеграция B+Tree с SQL после проверок восстановления.
- Связка клиент/API/БД.
- Развитие self-host A5.11b.
- Сборки Windows/macOS и реальные браузерные/Android-тесты.
- Критерии beta и стабильности.

[Full roadmap](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/ROADMAP.md).
