## Небольшая программа на Sedrava

~~~text title="hello.sdr"
app "Hello Sedrava"
state count = 0
action add: count = count + 1
rule count >= 0 and count <= 10
test once: add -> count == 1
screen main:
    text "Hello Sedrava"
    value count
    button "Add" -> add
~~~

Команда <code>sedrava check</code> проверяет программу, <code>sedrava test</code> запускает встроенные тесты, а <code>sedrava build web</code> и <code>sedrava build android</code> создают приложения.

## Единая экосистема

Типизированное состояние, записи, ограниченные коллекции, функции, навигация, Unicode, импорты и локальные пакеты. Web/Site/WebApp, Kotlin/Compose, trusted Host, локальный HTTP и SQL API A21 с ролями и ограниченными транзакциями. Self-host A5.11b — отдельный эксперимент. B25 пока не backend SQL.
