## Небольшая программа на Sedrava

~~~text title="hello.sdr"
app "Hello Sedrava"
state count = 0
action add: count = count + 1
rule count >= 0 and count <= 10
test once: add -> count == 1
screen main:
    text "Hello Sedrava"
    value count
    button "Add" -> add
~~~

Команда <code>sedrava check</code> проверяет программу, <code>sedrava test</code> запускает встроенные тесты, а <code>sedrava build web</code> и <code>sedrava build android</code> создают приложения.
