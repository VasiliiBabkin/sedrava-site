## Предыдущая стабильная версия: Sedrava 0.10.0

**0.10.0** выпущена 31 октября 2026 года: [релиз на GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0) · [пакет на PyPI](https://pypi.org/project/sedrava/0.10.0/). Это прежняя стабильная версия. В неё входят текстовые значения, записи, ограниченные коллекции и проверяемая многоэкранная навигация в прежних приложениях.

## 0.11.0rc1 — опубликован экспериментальный релиз-кандидат

[GitHub Pre-release](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.11.0rc1) · [Пакет PyPI](https://pypi.org/project/sedrava/0.11.0rc1/).

Sedrava **0.11.0rc1** опубликована из проверенного коммита 6051310a2ba2d542966588f12e0360c3f7c2a4d9. Публикация на GitHub и PyPI успешно завершилась. Это **экспериментальный кандидат, не стабильная 0.11.0**.

Установка в отдельном виртуальном окружении:

~~~sh
python -m pip install sedrava==0.11.0rc1
sedrava --version
~~~

В выпуск вошли генерация адаптивных сайтов (build site), интерактивных браузерных приложений (build webapp), типизированные компоненты и чистые функции, запросы к коллекциям, формы, таблицы, диалоги, маршруты и проверяемый HTTP-клиент. Прежние Web/Android-генераторы сохранены. [Примеры: сайт, задачи, каталог и CRM](https://github.com/VasiliiBabkin/sedrava/tree/v0.11.0rc1/examples).

Проверены реальное обновление 0.10.0 до 0.11.0rc1 и обратная установка, хранилище в Chromium/Firefox/WebKit и обновление отладочного APK на Android API 35. [Подробный отчёт](https://github.com/VasiliiBabkin/sedrava/blob/v0.11.0rc1/docs/UPGRADE_AUDIT_011.md).

Ограничения: нет встроенного доверенного сервера, SQLite/PostgreSQL, аутентификации, разграничения прав, автоматических миграций, системы пакетов с пространствами имён и подтверждённых испытаний на физическом устройстве. HTTP-клиенту нужен отдельный сервер. Откат промышленного Android-приложения не гарантирован.

## Последняя стабильная версия: Sedrava 0.11.0

[Стабильный релиз GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.11.0) · [Пакет PyPI 0.11.0](https://pypi.org/project/sedrava/0.11.0/).

**0.11.0** опубликована после независимых испытаний релиз-кандидата 0.11.0rc1. Проверенный исходный коммит — `c9cde75e3d2e2c7eafeeaec10c73fec627816e68`; Android versionCode — `11002`, выше предварительной версии `11001`.

Установить в отдельное виртуальное окружение Python:

~~~sh
python -m pip install sedrava==0.11.0
sedrava --version
~~~

В выпуск вошли многостраничные адаптивные сайты (`build site`), браузерные WebApp (`build webapp`), типизированные компоненты, чистые функции, ограниченные коллекции, формы, диалоги, таблицы, маршруты и проверяемый HTTP-клиент GET/POST/PUT/PATCH/DELETE. Примеры: сайт, задачи, каталог и CRM. Совместимость с прежними приложениями 0.10 для Web и Android сохранена в проверенном объёме.

[Критерии стабильного выпуска](https://github.com/VasiliiBabkin/sedrava/blob/v0.11.0/docs/STABLE_RELEASE_GATES_011.md): реальные установки 0.10 → 0.11 → 0.10 и 0.11rc1 → 0.11 → RC, браузеры Chromium/Firefox/WebKit и обновление Android API35. Это **не сертификат промышленной готовности**. Пока нет доверенного серверного генератора, SQLite/PostgreSQL, авторизации, разграничения прав, автоматических миграций, проверки на физическом Android и гарантий отката производственного APK. Пространства имён и пакеты остаются экспериментальной работой над 0.12.

## 0.12.0a1 — запланированная экспериментальная альфа, ещё НЕ опубликована

В отдельных, ещё не объединённых ветках реализованы [пространства имён — PR #39](https://github.com/VasiliiBabkin/sedrava/pull/39), [диагностика исходных файлов — PR #40](https://github.com/VasiliiBabkin/sedrava/pull/40) и [локальные пакеты с lockfile — PR #41](https://github.com/VasiliiBabkin/sedrava/pull/41). Обозначение `0.12.0a1` пока является планом выпуска, не доступной для установки версией. Полноценной таблицы символов в типизированном IR и сетевого реестра пакетов пока нет.

## Экспериментальная серверная платформа — ещё НЕ опубликована

В [PR #48](https://github.com/VasiliiBabkin/sedrava/pull/48) готовится ограниченный ASGI-сервер с проверкой состояния, декларациями таблиц SQLite, миграциями только вперёд и резервным копированием. **Это не входит** в опубликованную 0.11.0 или готовящуюся 0.12. Нет CRUD-маршрутов, авторизации, изоляции пользователей и подтверждённого промышленного развёртывания. [Черновая документация серверного среза](https://github.com/VasiliiBabkin/sedrava/blob/feature/013-server-sqlite-migrations-a1/docs/SERVER_013_EXPERIMENTAL.ru.md).

## Важные ограничения

Выпущенная Sedrava и готовящиеся кандидаты пока не создают доверенный сервер с SQLite/PostgreSQL, авторизацией и разграничением данных пользователей. HTTP в браузере — это клиент внешнего сервиса, а не встроенный сервер.

Этот официальный сайт документации собирается с помощью **Astro/Starlight**. Отдельно существует [демонстрационная площадка, собранная из Sedrava](https://dev.virtreal.ru/), и [репозиторий сайта](https://github.com/VasiliiBabkin/sedrava-site). Это разные механизмы сборки.
