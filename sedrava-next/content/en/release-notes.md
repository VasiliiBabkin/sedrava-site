## Published Sedrava 0.10.0

Released 31 October 2026 on [GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0) and [PyPI](https://pypi.org/project/sedrava/0.10.0/). It adds Unicode text, typed records, bounded collections, atomic actions, strict persistence and multiple screens to the earlier declarative Web/Android core.

```sh
python -m pip install sedrava==0.10.0
sedrava --version
```

This experimental language release is not production certification or a 1.0 compatibility commitment. APK compilation needs a separate Android toolchain. See [compatibility](/compatibility/) and [full release notes](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/RELEASE_NOTES_0_10_0.md).
