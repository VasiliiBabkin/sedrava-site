## Программы и версии

Опубликованная 0.10.0 сохраняет регрессионные примеры 0.9. Экспериментальная 0.11 не обещает стабильность и автоматическую миграцию. Закрепляйте компилятор и сохраняйте исходные проекты.

## Сохранённые данные

Ошибочный JSON, повторяющиеся ID, неверные типы, превышение лимитов и несовместимый fingerprint отклоняют восстановление целиком. Исходные повреждённые данные сохраняются, автоматическая запись блокируется: значения по умолчанию не заменяют их незаметно. Изменение полей/вместимости/persist может отклонить прежние данные. Автоматической миграции нет.

Browser storage локален, зависит от origin/path/имени, не зашифрован и может быть удалён браузером/пользователем. Reset примера явно удаляет только его хранилище, не весь origin.

## Обновление Android

Нужны прежние application ID/ключ подписи и возрастающий versionCode. Чистая установка не проверяет обновление. Переименование приложения может изменить default ID; заранее задавайте явный устойчивый ID. Приёмка конечного APK 0.10 на физическом устройстве не документирована.

[Полный контракт совместимости](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/COMPATIBILITY_010.md).
