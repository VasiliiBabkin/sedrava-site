## Опубликованная Sedrava 0.10.0

Выпущена 31 октября 2026 на [GitHub](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0) и [PyPI](https://pypi.org/project/sedrava/0.10.0/). Добавлены Unicode-текст, записи, ограниченные коллекции, атомарность, строгое хранение и несколько экранов поверх прежнего декларативного Web/Android-ядра.

```sh
python -m pip install sedrava==0.10.0
sedrava --version
```

Экспериментальный выпуск не является промышленной сертификацией и гарантией 1.0. Для APK нужен отдельный toolchain. [Совместимость](/ru/compatibility/), [полные заметки](https://github.com/VasiliiBabkin/sedrava/blob/main/docs/RELEASE_NOTES_0_10_0.md).
