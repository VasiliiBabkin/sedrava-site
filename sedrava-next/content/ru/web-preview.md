## Что работает здесь

Этот сайт написан на Sedrava. Страницы site, Markdown, локальный поиск и встроенные WebApp компилируются экспериментальным компилятором [PR #36](https://github.com/VasiliiBabkin/sedrava/pull/36) и [расширением документации #37](https://github.com/VasiliiBabkin/sedrava/pull/37). [Происхождение](/ru/provenance/) закрепляет реальные коммиты. Metadata пакета пока сохраняет 0.10.0; опубликованный пакет не содержит эти дополнения.

## Возможности и границы

Адаптивные компоненты, локальные CSS/шрифты, управляемые модули, чистые функции, запросы коллекций, формы/таблицы/диалоги, hash routes и публичный типизированный HTTP экспериментальны. [Примеры](/ru/examples/) — настоящие программы. HTTP-каталог явно ограничен тестовым endpoint CI до появления согласованного реального сервера на staging.

Примеры — доверенный код автора с общим origin, не изолированный playground. Нет редактора произвольного кода, секретов, обхода CORS, auth/БД или безопасного сгенерированного backend. Есть точный код, копирование/скачивание, перезагрузка и отдельный reset.

## Выпуск и размещение

Релиз 0.11, публикация пакета и production cutover не выполняются. Выход — статические HTML/CSS/локальные скрипты для Nginx. Размещение dev требует отдельного шлюза и реальных каталога/учётных данных. Preview-ветку нельзя преждевременно объединять с production main.
