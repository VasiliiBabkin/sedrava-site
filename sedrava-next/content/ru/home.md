Меньше служебного кода. Больше смысла.

## Состояния. Действия. Правила. Приложение.

Sedrava — экспериментальный декларативный язык программирования. Опиши поведение небольшого приложения один раз, а затем создай автономную веб-страницу или проект Android на Jetpack Compose.

## Один исходник — одинаковые правила

01 / ОПИШИ

### Объяви состояние

Целые числа, логические и текстовые значения, типизированные записи, ограниченные коллекции и вычисляемые поля.

02 / ЗАЩИТИ

### Задай инварианты

Действия атомарны: нарушение итогового правила или ошибка вычисления не приводят к частичному изменению состояния.

03 / СОЗДАЙ

### Собери под две платформы

Из одной программы генерируется самостоятельная веб-страница или исходники нативного Android-проекта.

## Небольшая программа на Sedrava


~~~text title="hello.sdr"
app "Hello Sedrava"
state count = 0
action add: count = count + 1
rule count >= 0 and count <= 10
test once: add -> count == 1
screen main:
    text "Hello Sedrava"
    value count
    button "Add" -> add
~~~


Команда `sedrava check` проверяет программу, `sedrava test` запускает встроенные тесты, а `sedrava build web` и `sedrava build android` создают приложения.
